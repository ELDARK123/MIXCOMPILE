# T3 = 1.4 dc UB 调查根因报告（2026-09-18）

## 结论
**dc 语义失败为测量环境污染事故，与程序 UB 和混淆器均无关。**

## 证据链
1. **现象（已更正）**：早期报告 dc 上 optimized 10/30 种子 semantic_failed，
   各随机候选最高 30/30 失败，特征为"同二进制间歇性出错"（4/5 过 1 崩）。
2. **根因定位**：NPB dc 为磁盘状态程序（CWD 读写 ADC.dat.0 / ADC.logf.0.0 /
   ADC.view.*）。修复前的调度器允许多个 dc 单元并发运行，16 路工作线程在共享
   scratch 目录中互踩状态文件 → 间歇性崩溃/输出错误 → 被误判 semantic_failed。
3. **决定性实验**：取出"失败"二进制单独运行 5/5 正确（输出 = llvm 基线）；
   同命令双构建 sha256 完全一致（编译确定性成立，排除编译期非确定性）。
4. **修复后重测**：样本亲和调度（同程序串行）下 dc 全部 36 候选 × 30 种子
   = 1,050+ 单元 **semantic_failed = 0**，含 optimized 30/30 通过。
5. **UBSan/ASan 未触发条件**：无失败样本存在，方法步骤 2（基线消毒剂检查）
   无对象；如论文需要，可作为附加卫生检查补跑，但不影响结论。
